Installation von R und Positron

Für die Übungen brauchen Sie zwei Programme:

  • R: die Programmiersprache, mit der wir Daten auswerten und plotten
  • Positron: die Arbeitsumgebung, in der Sie R-Code und Quarto-Dokumente schreiben (Quarto ist in Positron schon enthalten)

Beide Programme sind kostenlos. Installieren Sie zuerst R und danach Positron.

1. R installieren

Windows

  1. Öffnen Sie https://cran.r-project.org/bin/windows/base/.
  2. Klicken Sie auf Download R-4.x.x for Windows.
  3. Starten Sie die heruntergeladene Datei und übernehmen Sie in allen Schritten die Voreinstellungen.

macOS

  1. Öffnen Sie https://cran.r-project.org/bin/macosx/.
  2. Wählen Sie das passende Paket für Ihren Prozessor:
    • Apple Silicon (M1, M2, M3, …): Datei mit arm64 im Namen
    • Intel: Datei mit x86_64 im Namen
    Welchen Prozessor Ihr Mac hat, steht unter Apfel-Menü → Über diesen Mac → Chip bzw. Prozessor.
  3. Öffnen Sie die .pkg-Datei und folgen Sie dem Installer.

2. Positron installieren

  1. Öffnen Sie https://positron.posit.co/download.html.
  2. Laden Sie die Version für Ihr Betriebssystem herunter:
    • Windows: den User Installer. Dafür brauchen Sie keine Administratorrechte.
    • macOS: die .dmg-Datei. Öffnen Sie sie und ziehen Sie Positron in den Ordner Programme.
  3. Starten Sie Positron.

3. Prüfen, ob alles funktioniert

  1. Positron findet R beim Start von selbst. Oben rechts im Fenster steht dann z.B. R 4.x.x. Wenn dort nichts steht, klicken Sie auf die Stelle und wählen Sie R aus.
  2. Unten im Fenster ist die Konsole. Geben Sie dort ein: 
    1 + 1
    Erscheint [1] 2, dann funktioniert R.

Wenn etwas nicht klappt

  • Positron findet R nicht: Haben Sie R erst nach Positron installiert, starten Sie Positron neu.
  • Fehlermeldungen allgemein: Machen Sie einen Screenshot der vollständigen Meldung und bringen Sie ihn mit in die Übung.
